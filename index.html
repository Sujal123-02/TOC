Mathematical Foundations

Regex and Finite Automata

The theoretical pipeline connecting Regular Expressions, Nondeterministic Finite Automata (NFA), Deterministic Finite Automata (DFA), and state minimization.

What is a Regular Expression?

In formal language theory, a Regular Expression (RE) is an algebraic notation defining a language over an alphabet Σ. It uses base atomic symbols (ε, ∅, and characters from Σ) combined recursively through three fundamental operations: concatenation ($r_1 \cdot r_2$), union / alternation ($r_1 \mid r_2$), and Kleene closure ($r^*$).

What is a Regular Language?

A language $L \subseteq \Sigma^*$ is regular if and only if there exists a finite automaton (DFA or NFA) that accepts it, or equivalently, a regular expression that generates it (Kleene's Theorem). In the Chomsky Hierarchy, regular languages occupy Type 3, the simplest and most computationally efficient language class.

NFA vs. DFA

An NFA (5-tuple $(Q, \Sigma, \delta, q_0, F)$) permits multiple transitions for a given symbol and allows silent ε-transitions without consuming input. A DFA has no ε-transitions and possesses strictly one deterministic next state $\delta(q, a)$ for every state-symbol pair, guaranteeing $O(n)$ scanning time for a string of length $n$.

Conversion & Pattern Matching

A regular expression is converted into an $\epsilon$-NFA using Thompson's Construction. Next, the NFA is converted into an equivalent DFA via Subset Construction (Powerset Construction). Finally, redundant states are combined using Hopcroft's DFA Minimization to produce the minimal unique state machine used by high-performance pattern matchers.

Case Study: Regular Expression a(b|c)

To demonstrate the formal translation without overwhelming diagrammatic complexity, we study the classical expression:

  • Alphabet: Σ = {a, b, c}
  • Language: L = {ab, ac}
  • Accepted Strings: ab, ac (exactly two words)
  • Rejected Strings: a, aa, abc, bc, ba, ε, etc.

Why is L regular? The language is strictly finite ($|L| = 2$). Any finite language over an alphabet is trivially regular because it can be expressed as a finite union of single-word regular expressions ($ab \mid ac$) and accepted by a finite state automaton with no loops on accepting paths.

3. DFA Minimization & State Equivalence

Partitioning states into equivalence classes to establish the unique minimal DFA.

Using the Table-Filling / Hopcroft Partitioning Algorithm:

  1. Initial Partition ($P_0$): Separate states into non-accepting and accepting sets:
    Group 1 (Non-accepting): {A, B, T}  |  Group 2 (Accepting): {C, D}
  2. Check Non-Accepting Group {A, B, T}:
    • On input 'a': State $A \to B$ (Group 1), while State $B \to T$ (Group 1).
    • On input 'b': State $A \to T$ (Group 1), while State $B \to C$ (Group 2).
    Because State $B$ transitions into the accepting group on 'b' while $A$ and $T$ do not, $B$ is distinguished from $\{A, T\}$. Further, $A$ transitions to $B$ on 'a' while $T$ loops on $T$, separating $A$ from $T$.
    ⇒ Non-accepting states divide completely into singleton sets: {A}, {B}, {T}.
  3. Check Accepting Group {C, D}:
    • On input 'a': $\delta(C, a) = T$ and $\delta(D, a) = T$ (identical next state).
    • On input 'b': $\delta(C, b) = T$ and $\delta(D, b) = T$ (identical next state).
    • On input 'c': $\delta(C, c) = T$ and $\delta(D, c) = T$ (identical next state).
    For every symbol in the alphabet Σ, both $C$ and $D$ transition to exactly the same state $T$. Therefore, $C$ and $D$ are 100% indistinguishable ($C \equiv D$) and can be safely merged into a single state CD.
